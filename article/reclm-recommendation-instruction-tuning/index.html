用户侧画像比物品侧更值钱：RecLM 的推荐指令微调

发表于2026-10-19|更新于2026-10-21|推荐系统生成式推荐
|总字数:1.4k|阅读时长:4分钟|浏览量:

论文：arXiv 2412.19302 · 代码：GitHub

ID-based 推荐系统的结构性缺陷是：用户和物品只是索引。模型从一个随机初始化的向量开始，靠交互数据把它训练出意义。这让它在冷启动时几乎无法工作——一个新物品没有任何交互，它的 ID 嵌入就等于噪声。

LLM 有语义理解能力，看起来是答案。但直接拿来用会撞上第二面墙：LLM 懂语言，不懂协同信号。”买过 A 的人往往也买过 B”这种关系既不在预训练语料里，也不是一段文本能自然表达的。

RecLM 的思路是把这两件事接起来：把协同关系做成指令的一部分，让 LLM 在理解行为上下文的前提下生成画像。

一、方法：两轮协同指令 + RL 精炼画像

1. 先把协同信号”翻译”成 LLM 能读的形式

框架的第一层是文本化的用户/物品表示——不是只把物品标题拼起来，而是在文本表示中注入协同关系：用户的历史交互物品序列、以及与之相似的用户的行为。

2. 两轮协同指令微调

这是论文的核心设计。基于 LLM 的画像生成有一个天然障碍：画像没有 ground truth——你无法标注”正确的用户画像”应该长什么样。RecLM 的做法是用两轮对话把这个问题绕开：

关键在于**第一轮的输入里同时给了”我做过什么”和”和我相似的人在做什么”**——后者正是协同信号。模型被要求从两组行为里归纳出画像，而不是仅凭单个用户的稀疏历史。

3. 用强化学习精炼画像质量

画像质量难以用监督损失刻画，论文引入 RL 来补这一环：训练一个奖励模型评估生成画像的质量（输入 [Q, R] 对，输出标量分数），再用它作为奖励信号去微调画像生成。

上图对比了两者产物——不加 RL 时画像偏向复述行为，加 RL 后更接近”偏好归纳”。

二、实验：提升幅度与骨干强弱反相关

数据用 MIND、Netflix 以及一个大规模工业数据集；评价用 R@20 / NDCG@20 与 all-rank 设定。RecLM 是模型无关（model-agnostic）的——它不是替换推荐器，而是给现有推荐器换上更好的用户/物品表示。

主结果

这张表有一个非常清晰的规律：骨干越弱，增益越大。

  • LightGCN 在 MIND 上翻了倍（+102.57%），SGL 在 Netflix 上 +184.48%；

  • 而 NCF 只 +6.59%、BiasMF 在 MIND 上 +5.27%。

原因不难理解：RecLM 补的是”ID 表示缺乏语义”这个短板。以 ID 嵌入为核心的浅层模型（BiasMF、NCF）本身已把 ID 之间的关联学得比较充分，文本化带来的增量有限；而图模型（LightGCN、SGL）在冷启动节点上根本拿不到有效嵌入，换成”有语义的文本表示”是质变。

消融：一个反直觉结果

MIND 数据集、LightGCN / SGL 骨干：

看第三行：去掉物品侧增强之后，指标反而从 0.0389 涨到 0.0719——也就是说，物品侧的 LLM 画像贡献了负收益。

论文的完整模型（0.0788）仍然最好，说明物品增强并非全无价值，但它只有在与用户侧增强配合时才起作用；单独加它是有害的。结合另一个事实看会更清楚：去掉用户增强会掉点（0.0389 → 0.0302），说明用户侧画像才是主要贡献者。

这个结果很实用：在冷启动/文本化的方案里，”用户侧”和”物品侧”的价值是不对称的。物品的描述文本往往本身就很短、很模板化（标题+类目），LLM 从里面能榨出的信息有限，反而容易引入噪声；而用户行为序列的信息密度高得多。

成本

开销增加与骨干的复杂度反相关：骨干本身越贵，RecLM 的相对开销越小（SGL +0.15%、SimGCL +2.28%）。而浅层模型（BiasMF +25.18%）因为基线太快，相对增幅看起来大，绝对增量仍在秒级。

对工程来说这是个好消息：加画像增强不会让训练时间失控，尤其是当骨干已经是图模型时。

三、总结

RecLM 的贡献是把”LLM 用于推荐”这件事落在了表示层而不是排序层：

  1. 模型无关：它不替代推荐器，而是替换用户/物品表示。这意味着它可以挂到任何 ID-based 系统上，改动面小。

  2. 两轮指令解决了”画像无标注”这个死结：第一轮从”我的行为 + 相似用户的行为”生成画像，第二轮用画像做判断——用下游任务的效果间接监督画像质量。

  3. 两个反直觉但要记住的结论：

  • 增益与骨干强弱反相关：ID 嵌入越弱、越依赖协同关系的模型，收益越大（LightGCN +102% vs NCF +6.6%）。
  • 用户侧与物品侧不对称：去掉物品增强反而涨点（0.0389 → 0.0719），说明物品描述文本的信息密度不足以支撑画像，做同类方案时应优先把预算花在用户侧。
  1. 成本可控：相对开销 +0.15% 到 +25%，且骨干越复杂占比越低。
