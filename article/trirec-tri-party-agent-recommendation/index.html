推荐不该只服务用户：TriRec 的三方智能体框架

发表于2026-02-13|更新于2026-10-18|推荐系统生成式推荐
|总字数:2k|阅读时长:7分钟|浏览量:

论文：arXiv 2603.10673 · 代码：GitHub

推荐系统长期按”用户中心“设计：目标是让用户看到想看的东西。但这个假设在平台生态里并不完整——平台上还有内容创作者（希望自己的作品被看见）和平台（希望生态健康、供给不被头部垄断）。当推荐只服务用户时，创作者侧的利益和平台的长期供给健康会被牺牲。

这篇论文提出三方框架（TriRec）：把用户、物品（创作者）、平台三个利益方都建进模型，用智能体来承载各自的偏好表达。

一、问题形式化：三个利益方要同时满足

论文先把”多利益相关方效用”形式化，明确每一方在意什么：

利益方 诉求 对应指标
用户 推荐相关、符合偏好 NDCG、MRR ↑
物品/创作者 自己的物品获得曝光 EIU（曝光）↑
平台 生态公平：不让头部垄断、不让尾部无人问津 DGU、MGU ↓（差异性越大越不公平）

这里有个结构性张力：用户要相关度，平台要公平，而”最相关的”通常是”最热门的”——提升公平往往会牺牲一部分精度。论文要回答的就是：能不能两头都拿。

“打破用户中心”的含义：不是说不服务用户，而是说不把用户效用当作唯一目标函数——把公平显式地写进优化目标。

二、方法：两阶段

阶段 1：生成式个性化自我推广（创作者侧）

这一阶段的设想比较新颖：**让物品（创作者侧）用智能体去”自我推广”**。

具体地，物品 Agent 生成自我描述/卖点（个性化地针对不同用户），与用户 Agent 做偏好交互。这一步产出的是”语义层面的匹配”——不是靠 ID 共现，而是靠 LLM 理解”这个物品对这类用户意味着什么”。

阶段 2：平台主导的多目标重排

第一阶段给出的相关度排序，在第二阶段被平台 Agent 重新平衡：在相关度和公平性之间取折中，输出最终列表。

两阶段的先后顺序是有意义的：先让每个物品充分表达自己（避免小物品因为没有曝光而被提前淘汰），再由平台视角做全局平衡。如果反过来（先按热度筛再重排），小物品根本没有进入候选池的机会。

论文对这张表的解读是关键，值得完整引用它的逻辑：

SCRUF-D（专做公平排序的方法）拿到了最低的 DGU/MGU，但它的 NDCG 明显很低。而 TriRec 在保持最高 NDCG 的同时，公平性指标（DGU 0.160 / MGU 0.147）也达到了有竞争力的水平。

也就是说：**”纯公平”方案会牺牲大量精度，”纯精度”方案（LTP-MMF 这类）公平性最差；TriRec 的定位是在这条折中考线上找到更靠前的点。** 论文在 Movies & TV、Goodreads YA、Steam Games 上，TriRec 的 DGU/MGU 均为最优。

这个结果形态值得记住：在公平性研究里，”指标最优” 与 “折中曲线最优” 是两件事，看单点数字容易被误导。

这张表里有几件事值得单独说：

  1. **去掉阶段 1 掉 31.7%**（论文原文的表述）：LLM 驱动的语义交互对细粒度偏好对齐是不可省的。
  2. 去掉用户效用掉得最狠（NDCG 0.2634）：这是最有意思的结果——**”打破用户中心”不等于”放弃用户”**。把用户效用从目标里彻底拿掉，精度会崩到 0.26 水平。真正的意思应该是”用户效用是必要条件，但不是唯一目标”。
  3. 去掉动态权重 α_k 让公平性指标变得”看起来很好”（DGU 0.1301、MGU 0.1296，比完整的 0.135+ 还低）。这提醒我们：公平指标不能单独看——去掉动态调整后精度掉到 0.4635，公平数字好看是因为排序策略退化了，而不是因为更公平。
  4. 去掉平台效用（d）与去掉物品效用（g）影响相对小，说明这两个效用项更多是”约束”而非”驱动”。

四、总结与局限

TriRec 的核心主张是：推荐的目标函数应该显式包含多个利益方，而不是隐含地假设”服务好用户就等于服务好生态”。

四点可迁移的判断：

  1. 公平与精度不是二选一，而是要找到更好的折中点：SCRUF-D 拿到最低的不公平指标但精度很低，LTP-MMF 精度高但公平最差。评估这类方法要看折中曲线，而不是单点最优。
  2. **”打破用户中心”≠”去掉用户效用”**：消融显示去掉用户效用精度直接崩（0.2634）。正确的表述是”用户效用是底线约束，公平是额外目标”。
  3. 顺序很重要：先表达、再平衡：如果先按热度筛选候选，小物品根本没有机会进入重排阶段。
  4. 公平指标必须配精度一起看：去掉动态权重后公平数字反而变好，但那是退化导致的假象。

论文在结论里也主动列了局限——其中值得注意的一点是多利益相关方的效用权重（λ_item 等）本身如何设定仍带主观性：不同平台对”公平”的定义不同，这决定了这套框架需要按业务调参，而不是拿来即用。
