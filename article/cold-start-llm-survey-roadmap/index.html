冷启动的四条路线：内容、图、跨域、语言模型该怎么选

发表于2026-10-19|更新于2026-10-21|未分类
|总字数:1.8k|阅读时长:5分钟|浏览量:

论文：arXiv 2501.01945 · 代码：GitHub

冷启动是推荐系统里最”顽固”的问题：新用户和新物品没有任何交互历史，而推荐模型几乎全部依赖交互历史。过去十年围绕它提出的方法非常多，但它们分散在内容特征、图结构、跨域迁移、语言模型四条互不相通的线上。这篇综述的价值在于把这四条线装进同一个坐标系，并说清每类方法到底”补的是什么信息”。

一、先定义清楚：冷启动不止一种

综述先把任务形式化。用户集 U、物品集 V，冷启动的一般设定是把实例划成有交互的 Û/ V̂ 与冷启动的 U/V，然后在不同阶段（训练 / 调参 / 测试）是否允许看到 U/V 的交互，组合出多种任务设定：

划分方式可以是按交互数阈值（交互数 k 以下算冷），也可以是按时间划分。这一步很关键——不同论文报的”冷启动提升”经常不是同一个任务，横向比较前必须先对齐这张表。

二、四条路线：补的信息不同，解决的问题也不同

综述把现有方法按”冷实例能拿到的额外信息来自哪里”分成四条路线。

路线 1：内容特征——用属性替代交互

当交互缺失，用户画像、评论、物品名称与描述这些固有属性是唯一立即可用的信号。这条线再分两小类：

  • 数据不完整学习：只用内容信息学习冷用户/物品的表示。典型是鲁棒协同训练（同时优化行为表示与内容表示，用鲁棒泛化策略抗噪）与自编码器（编码器-解码器统一框架，编码器用变分或去噪策略增强鲁棒性）。

  • 数据高效学习：仍有少量交互，目标是把它用尽。核心是元学习——先在多用户历史上预训练，再快速适配到新用户。综述把 MeLU 列为这条线的奠基工作，它把 MAML（Model-Agnostic Meta-Learning） 引入冷启动偏好估计；后续工作进一步从”共享的全局初始化”推进到”个性化参数适配“。

这两小类的分工很清楚：前者解决”完全没数据”，后者解决”数据太少”。

路线 2：图关系——把冷节点挂到图上去

如果交互图里冷节点是孤岛，那就要么补边、要么换图、要么改聚合方式。综述用一张图概括了三种策略：

  1. 交互图增强：为冷实例补充图关系信息，把原始用户—物品二部图补全。

  2. 图关系扩展：把图换成信息更丰富的形态——异构图（扩展节点/边类型）、属性图（靠属性相似性连边）、知识图谱（实体—关系的结构化语义库）。

  3. 聚合器改进：图没变，改的是怎么聚合。一个是聚合范围扩展（不再只看局部邻域，纳入全局或长程上下文，从而把冷节点和远端信息连起来），另一个是域知识迁移（把别的域学到的结构模式迁过来）。

对冷启动而言，”换图”往往比”改模型”更有效——因为冷启动的瓶颈是结构性信息缺失，而不是聚合函数不够强。

路线 3：域信息——借别人的数据

很多平台本身就是长尾的，但”别的平台/别的域”可能有充足交互。这条线的三种做法：

三者的假设强度不同：迁移假设”能映射”，对齐假设”能拉近”，不变表示学习假设”本来就有共享子空间”。假设越强，适用面越窄但通常效果越好——这是选型时要权衡的。

路线 4：LLM 世界知识——把预训练语料当外部知识库

这是综述相对早期冷启动综述新增的部分（也是标题里点出的时代特征）。LLM 在冷启动上的角色被分成两种：

A. LLM 作为推荐器本身

  • 直接提示：把推荐任务写成自然语言，让预训练模型（如 GPT-2 级别）零样本生成推荐，不需要任务特定训练。

  • 多步提示：直接提示的结果通常不如全量训练的传统方法，因此用多步推理把任务拆开逐步引导。

B. LLM 作为知识增强器

这是更被看好的一路，因为它不要求 LLM 直接给出排序：

  • 模态增强表示：传统推荐从随机初始化的 ID 嵌入开始，冷物品的 ID 嵌入等于噪声。用 LLM 从文本/图像生成有语义的表示替代随机初始化。

  • 域增强表示：跨域推荐通常要设计复杂的对齐结构；LLM 可以先把两域的内容映射到统一语义空间，简化架构。

三、还没解决的五个方向

综述末尾给出五个开放方向：

  1. 多模态冷启动：视觉、文本等多模态信息能提供更丰富的表示，但如何对齐与去噪仍是难题。

  2. 推荐基础模型：NLP 领域”预训练 + 轻量适配”的范式能否迁移到推荐，是当前最大的开放问题之一。

  3. 效率：现有方法大多在离线设定下验证，大规模在线部署时面临显著挑战——这一点在综述里被单独点出。

  4. 数据隐私：跨域迁移天然涉及跨平台数据共享，与合规要求存在张力。

  5. 基准与统一评测：这是最实际的一条。前面那张任务定义表说明同一句”冷启动”在不同论文里指的可能是不同任务，缺少统一基准会让指标无法比较。

四、总结

这份综述最大的贡献是给出选择依据：面对一个冷启动问题，先问”我能拿到什么额外信息”，答案决定走哪条路线。

三点判断：

  1. 先对齐任务定义再比指标：长尾、标准冷启动、”训练即冷启动”是三个不同任务，”提升 10%” 在不同设定下不是一个东西。

  2. **LLM 目前最稳的位置是”知识增强器”而非”推荐器”**：直接用提示做推荐仍打不过全量训练的传统方法，但用 LLM 生成语义表示替代随机初始化的 ID 嵌入，收益明确且风险低。

  3. 图路线的性价比最高：冷启动瓶颈是结构性信息缺失，而图扩展（异构图/属性图/知识图谱）正是直接补结构，逻辑最顺。
