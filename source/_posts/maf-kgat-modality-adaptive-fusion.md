> 论文：[DOI](https://doi.org/10.12677/csa.2026.163084)

多模态知识图谱推荐（MMKG Rec）的常见做法是：把视觉特征和知识图谱结构特征**在节点层面拼起来或按固定权重相加**，再送进图传播。这个做法有一个隐含假设——**每个物品的视觉信息质量差不多**。

真实数据里这个假设不成立：有的商品图清晰、信息量大；有的就是一张白底图或者模板图；还有一部分物品根本没有图。固定权重在这种情况下会让模型继续"听"那些没信息量的视觉特征，把噪声当成信号传下去。

MAF-KGAT 针对的就是这一点：**融合权重不该是全局常数，而应该是每个物品自己算出来的**。

---

## 一、方法：四层结构，门控在第三层之前发生

![MAF-KGAT 模型整体框架：输入层、表示学习层、图传播与任务层、损失函数](/images/b2648b423fe771551d501366217f130c.png)

如上图（论文图 1），模型分四部分：输入层、表示学习层、图传播与任务层、损失函数。其中**表示学习层里的模态自适应门控**是整篇论文的核心改动。

### 1. 输入：三类信号各自编码

- **用户–物品交互图**：协同过滤信号

- **知识图谱三元组 (h, r, t)**：物品的结构化关联

- **物品图像**：用预训练 **CLIP（ViT-B/32）** 提取 **512 维**视觉特征

### 2. 视觉侧：投影到结构空间再融合

原始视觉特征是 512 维，而结构嵌入是 64 维。论文没有直接拼接，而是先用一个**投影模块（线性层 + LeakyReLU + Dropout）把 512 维视觉特征映射到 64 维**——目的是让两种模态落在**同一个度量空间**里，否则"拼接"只是把两个量纲不同的向量接在一起，融合权重也就失去了可比性。

### 3. 门控融合：物品级、动态、带温度系数

这是论文与 MKGAT 的核心区别。门控网络用**两层 MLP + Softmax**计算每个物品的模态权重：

```plain text
g_i = Gate( e_i^vis, e_i^struct ) ∈ [0, 1]        （物品 i 的门控值）
```

关键性质：

- **粒度是物品级**：每个物品一个门控值，不是全数据集一个常数，也不是按类别分组的常数。这直接对应"模态质量因物品而异"这个现实。

- **带温度系数 T = 0.5**：Softmax 的温度控制权重分布的"软硬"。T 偏小会让门控趋近于硬选择（要么全靠视觉、要么全靠结构），T 偏大则退化为平均。0.5 是在两者之间取的折中。

- **语义是"偏向 ID 表示的程度"**：门控值 `g_i ∈ [0,1]` 被定义为物品**偏向协同过滤（ID embedding）表示的程度**——也就是"视觉信息不可信时，往结构信号那边倒"。

### 4. 图传播：KGAT 式的高阶聚合

门控融合后的物品表示进入**知识感知注意力网络**做高阶传播。聚合器用的是 **Bi-Interaction**：

```plain text
f(e_h, e_N(h)) = LeakyReLU( W1·(e_h + e_N(h)) + W2·(e_h ⊙ e_N(h)) )
```

即同时保留"加性项"与"元素级乘积项"，前者传递整体偏置，后者捕捉特征交叉。层维度设为 **[64, 32, 16]**，邻接矩阵用**随机游走归一化**稳定传播。

### 5. 损失：三部分联合

```plain text
L_total = L_cf + α·L_kg + β·L_gate
```

三部分各有明确职责：






**门控正则这一项值得单独说**：它约束门控值的分布不要偏离 0.5 太远。理由很直接——如果不加约束，门控网络容易在训练早期就把权重推向极端（例如全信结构、完全关掉视觉），从此不再利用另一模态。加正则相当于给融合比例一个"温和先验"：允许偏离，但别跑太远。

另外 `L_kg` 与 `L_cf` 是**交替优化**的，用小批量 Adam 分别更新嵌入损失与预测损失。

相对提升是对 **MKGAT**（最接近的工作，同样是 KGAT + 视觉特征）算的。这个对照很关键：它把"加视觉模态"和"**动态**融合视觉模态"两件事分开了——涨点来自后者。

### 两模态是互补的：t-SNE 证据

![t-SNE 可视化：CLIP 视觉嵌入与 KGAT 结构嵌入部分重叠但整体分布差异明显](/images/7c57c1b5e54a27d5c207024e17d62df9.png)

论文图 3 把线性投影后的 CLIP 视觉嵌入与 KGAT 结构嵌入做 t-SNE：两者**部分重叠但整体分布明显不同**。这是一条直接的设计依据——正因为两种模态在语义空间里既不重合也不完全无关，所以：

- **融合前保留模态差异**（先投影对齐、再拼接，而不是先平均）

- **高层用门控动态加权**（而非固定比例）

也解释了为什么"简单拼接"（0.1504）与"线性融合"（0.1556）都不如动态门控（0.1603）。

**冷启动**（Amazon Books 上交互 `<` 5 次的用户子集，表 6）：

**图像缺失**（表 7，随机移除不同比例图像特征）：







这组数字最能说明门控机制的价值：即使**随机扔掉 80% 的图像特征**，MAF-KGAT（0.1501）依然高于完全没有图像的 KGAT（0.1450）。性能是平滑退化而不是崩塌，说明门控确实在图像不可用时把权重交给了结构信号。

## 三、总结

MAF-KGAT 的结构很简洁——就是在 KGAT 前面插一个物品级的门控融合。它的价值集中在一条判断上：**多模态融合的权重应该是"学出来的、逐物品的"，而不是"设定的、全局的"**。

三处可以带走的结论：

1. **粒度决定了适应性**：门控做到物品级，才能应对"有的物品图有信息、有的没有"这种真实分布；静态融合（无论拼接还是线性加权）都做不到。

1. **融合前要先对齐空间**：512 维视觉特征先投影到 64 维结构空间，权重才有可比性。

1. **给融合比例加个温和先验**：门控正则（μ = 0.5）防止训练早期把某个模态彻底关掉。

1. **鲁棒性可被直接测量**：图像缺失扫描（0%→80%）是一条很有说服力的证据链——它证明了机制在"数据变坏"时的行为，而不只是"数据最好时"的峰值。

值得说明的两点边界：一是本文的视觉特征只用 CLIP 图像特征，文本模态未纳入（作者已列在 future work）；二是消融显示"动态门控相对线性融合"的增量（约 3 个百分点）小于"加视觉相对不加视觉"的增量——**模态本身的价值仍大于融合策略的价值**，这一点在评估投入产出时值得记住。
