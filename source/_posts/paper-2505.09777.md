> 论文：[arXiv 2505.09777](https://arxiv.org/abs/2505.09777) · PDF：[本地阅读](https://app.notion.com/papers/2505.09777.pdf)

多模态推荐系统（MRS）长期面临数据稀疏、冷启动和模态错位等难题，传统协同过滤与神经编码器虽不断演进，却难以在推理阶段灵活利用外部知识。大语言模型（LLM）的兴起为这一领域注入了新的可能：它们凭借预训练世界知识、语义推理和上下文学习能力，能够在无需重训练的情况下处理多样化的推荐输入，尤其适合冷启动与跨域场景。然而，LLM 的引入也带来了计算成本、黑盒 API 限制和推理延迟等现实约束，使得如何高效、可控地将 LLM 融入 MRS 成为亟待厘清的问题。

这篇综述由华为伦敦研究中心的 Alejo López-Ávila 与 Jinhua Du 撰写，发表于 arXiv（2025 年 5 月），旨在系统梳理 LLM 与 MRS 交叉领域的最新进展。与以往以编码器或损失函数为中心的综述不同，本文明确将 LLM 视为能够进行语义推理和动态适应的核心组件，而非静态的编码器-解码器。作者指出，现有 MRS 综述往往仅在未来方向中简要提及多模态 LLM，而聚焦 PLM 的推荐综述又多局限于 BERT 类架构，缺乏对上下文推理和工具增强能力的讨论。本文试图填补这一空白，提供一个以 LLM 为中心的前瞻性框架。

综述的核心矛盾在于：LLM 的强大通用能力与推荐系统对低延迟、领域特化和计算效率的刚性需求之间存在张力。一方面，提示工程和参数高效微调（如 LoRA、QLoRA）为低成本适配提供了可能；另一方面，黑盒 API 的不可控性、多模态对齐的信息损失以及智能体系统的工程复杂度，又限制了这些技术在实际部署中的普适性。作者并未回避这些权衡，而是在分类框架中逐一剖析各类方法的适用边界与代价。

本文的贡献可概括为四点：提出以 LLM 功能（提示、训练、数据适配）为核心的新分类法；引入来自序列推荐、知识感知推荐等相邻领域的可迁移技术，扩展 MRS 的设计空间；绘制当前趋势并识别研究空白；以及提供更全面的评估指标与数据集资源，包括 NLP 衍生指标（如 BLEURT）和 LLM 评估器。这些内容为后续研究提供了结构化的参考坐标。

## 一、方法：以 LLM 功能为轴的三层分类框架

综述的方法论并非实验性的，而是通过系统性文献检索与分类构建分析框架。作者将 LLM 在 MRS 中的集成方式划分为三大类：提示技术、训练策略和数据适配。这一划分刻意淡化传统编码器架构，转而聚焦 LLM 特有的推理、提示与模态适配能力。

### 1.1 提示技术：从硬提示到控制逻辑

提示是 LLM 融入 MRS 最轻量的方式，无需更新模型权重，尤其适合黑盒 API 或算力受限场景。作者将其细分为四类：硬提示、软提示、混合提示和控制逻辑。

硬提示使用固定模板引导 LLM 行为，包括人工设计的提示、基于规则的结构化模板以及推理导向的格式（如上下文学习、思维链）。例如，Sileo 等人利用电影列表形式的硬提示进行零样本推荐，而 CTRL 则通过手工模板将表格特征转化为自然语言输入。硬提示的优点是直观、可解释，但脆弱性明显——措辞的微小变化可能显著影响性能，且依赖人工设计，难以规模化。

软提示则引入可训练的连续嵌入（软 token），在冻结 LLM 的情况下进行任务适配。直接软提示（如 Prefix-Tuning、Prompt Tuning）将可学习向量注入输入空间；语义 ID 提示则将用户/物品 ID 映射为连续嵌入，绕过分词与自然语言格式化。TMF 将用户行为图向量作为软提示附加在文本描述之后，VIP5 和 PEPLER 则采用语义 ID 嵌入来增强个性化。软提示的代价是牺牲可解释性，且需要访问模型嵌入空间和训练循环。

混合提示结合固定硬提示与可学习软组件，在可解释性与适应性之间取得平衡。PEPLER 的混合框架将手工提示与软提示学习融合，EUIRec 则动态生成软提示以捕捉当前意图，同时用静态硬提示编码历史偏好。这类方法在冷启动和个性化场景中尤为有效。

控制逻辑提示通过多阶段、分支或条件流程协调多次 LLM 调用，支持复杂任务的分解与推理。AltFS 将特征选择分解为排序与验证阶段，IndustryScopeGPT 则利用蒙特卡洛树搜索结构化 LLM 交互。控制逻辑为推荐工作流提供了模块化、可解释的编排能力，但工程复杂度较高。

### 1.2 训练策略：参数适配、零调优与智能体

训练策略关注如何调整或使用 LLM 以适应下游推荐任务。作者将其分为参数适配、零调优使用、预训练多模态 LLM 和智能体系统四类。

参数适配包括全量微调、轻量适配器（LoRA、QLoRA）、指令微调、预训练-微调流水线、强化学习增强调优以及提示增强调优。LLAMA-E、LGIR 等采用 LoRA 进行领域适配，iLoRA 通过门控机制动态选择专家参与。PMMRec 结合多模态对比预训练与下游全量微调，在多个数据集上取得 SOTA。这类方法灵活性高，但需要访问模型权重和可观算力。

零调优使用则在冻结模型的状态下提取表示或生成中间输出，包括编码器表示、黑盒提示生成用户画像、标签/属性抽取、内容增强以及检索增强生成（RAG）。UniMP 使用冻结的模态编码器加轻量融合层，TagGPT 通过黑盒 LLM 从多模态输入生成标签。零调优部署简便，但缺乏任务特化能力。

预训练多模态 LLM（MLLM）通常以冻结或轻微微调的状态处理文本、视觉和结构化数据，分为多模态编码、生成式流水线和端到端架构三类。VIP5 通过适配器将 CLIP 视觉特征注入冻结 MLLM，MM-Rec 则集成 ViLBERT 进行新闻标题与图像的联合编码。MLLM 的零样本泛化能力强，但推理延迟是瓶颈。

智能体系统将 LLM 实例化为自主代理，具备规划、工具使用和反思能力。IndustryScopeGPT 使用四步 MCTS 硬提示，RecSysLLMsP 则用结构化提示实例化具有不同人格的 LLM 代理来模拟用户行为。智能体在个性化、可解释性和可控性方面展现出潜力，但仍处于发展阶段。

### 1.3 数据适配：将非文本模态转化为 LLM 可读形式

数据适配旨在将图像、表格、行为日志等非文本模态转化为 LLM 兼容的文本类表示。作者归纳了八类方法：知识图谱转换、语义 ID 转换、表格到文本转换、图像摘要、行为到文本摘要、提示融合、适配多模态融合以及代码类结构转换。

知识图谱转换利用 KG 统一异构数据，提供结构化语义关系，有助于缓解幻觉并增强可解释性。IndustryScopeGPT 构建多模态 KG 并通过 Cypher 查询与 LLM 集成，RecInDial 将对话链接到 DBpedia 子图。语义 ID 转换将用户/物品 ID 映射为语义 token 空间，PEPLER 和 TTDS 分别采用离散提示和向量量化语义索引。表格到文本转换通过模板或 ICL 将结构化表格转为自然语言，CTRL 和 AltFS 是典型代表。图像摘要使用 MLLM 将视觉输入转为文本描述，HLLM 将图像序列摘要为文本以提升可扩展性。行为到文本摘要则将点击、浏览等交互日志转化为自然语言总结，支持下游推理。

本文为综述论文，未进行新的实验。其分析基于所引用的原始论文中的实验设置与结果，涵盖推荐、搜索、公平性、特征选择、知识图谱构建等多种任务。下表汇总了综述所涉及的数据集、模型与评估资源。








由于综述未进行统一实验，无法提供主结果对比表。作者在正文中引述了若干代表性发现：PEPLER 在解释生成任务上优于基线；VIP5 在冷启动场景下性能提升显著；TMF 通过软提示融合多模态特征提升了推荐准确性；PMMRec 通过多模态对比学习预训练在多个数据集上取得 SOTA。这些结果来自各自原始论文，具体数值因数据集和实验设置而异，综述未进行跨论文的数值汇总或复现。

在消融与效率分析方面，综述同样未报告独立的消融实验。作者在讨论各类方法时，定性比较了不同策略的优缺点与适用场景，例如硬提示的脆弱性、软提示的可解释性代价、MLLM 的推理延迟以及智能体系统的工程复杂度。这些分析为理解方法边界提供了参考，但缺乏统一的量化证据。

## 三、总结

这篇综述以 LLM 的功能角色为轴，构建了提示、训练与数据适配三层分类框架，系统梳理了多模态推荐系统中 LLM 的集成模式。其核心机制在于将 LLM 视为动态推理代理而非静态编码器，强调提示工程、参数高效微调和模态转换在降低适配成本的同时，也引入了可解释性、延迟和工程复杂度等新权衡。

实验证据方面，综述本身不提供新实验，而是通过引述原始论文的结果来支撑分类框架的合理性。PEPLER、VIP5、TMF 和 PMMRec 等案例展示了不同集成策略在解释生成、冷启动和准确性上的潜力，但这些证据分散且缺乏统一评估，难以直接比较。综述的价值在于绘制了技术版图，而非验证某一方法的优越性。

限制与边界同样明显：LLM 的黑盒访问限制、推理延迟对实时推荐的影响、多模态转换中的信息损失，以及智能体系统的工程开销，都是实际部署中不可忽视的约束。此外，综述对评估指标和数据集的整理虽更全面，但仍依赖各原始论文的异质设置，跨研究比较仍需谨慎。

可迁移的设计启示在于：推荐系统 Agent 的开发可借鉴控制逻辑提示的多阶段流水线设计，利用语义 ID 和软提示实现轻量个性化，并通过 LLM 评估器和多目标指标（如多样性、公平性）来评估 Agent 的推荐质量与行为。这些思路为构建模块化、可扩展的推荐 Agent 提供了结构化的参考。
