# 科研城市自然地貌地图设计

## 目标

把现有论文足迹地图从“带高程的世界底图”升级为“自然地貌引导下的科研城市网络”：二维地图继续承担快速浏览，三维地图以山脉、海岸和城市区位为背景，重点呈现北京、杭州、新加坡、纽约等核心城市，以及高校、科研院所和企业总部对应的论文。

本次交付必须满足：

- GitHub Pages 静态部署可用，不需要 API Key 或新增付费服务。
- 二维首屏性能和请求数量不退化；MapLibre 与高程瓦片仍然按需加载。
- 三维模式失败时自动恢复 Leaflet 二维地图。
- 重点城市的论文、机构和图片全部来自现有数据；没有直接论文归属的城市明确显示为零，不借用其他城市数据。
- 风格沿用 Butterfly 网站的明亮、通透、圆角卡片语言，不采用纸张编辑部风格。

## 已确认的视觉方向

采用“地貌 → 核心城市 → 机构与论文”的混合叙事。

- 全球视角保留清晰的海陆、山脊和国家城市标注。
- 点击重点城市后，镜头先经过区域地貌，再抵达城市；北京显示燕山与华北平原关系，杭州显示东南丘陵与钱塘江湾，新加坡显示岛屿与海峡，纽约显示大西洋海岸与哈德逊河口。
- 自然地貌是空间背景，城市和研究机构是视觉高潮；论文标记始终位于最上层。
- 地形夸张按视角动态控制：全球约 `1.0`，城市抵达约 `1.35–1.45`，避免失真成游戏地图。

## 数据与排序

重点城市采用“人工保底 + 数据驱动补充”的混合机制。

### 人工保底

北京、杭州、新加坡、纽约始终出现在核心城市导航中。每个城市定义稳定坐标、区域切入点、最终镜头参数和中文地貌摘要。

### 数据驱动补充

从 `map_data.json` 聚合城市级记录，而不是按单个 school/company marker 排名：

- 论文数量：每篇计 10 分。
- 机构数量：每个去重机构计 4 分。
- 最近一年论文：每篇额外计 6 分。
- 人工核心城市：保底加权，但不会伪造论文数量。

自动候选取分数最高的城市，和人工核心城市去重后组成导航。城市详情合并同城的高校、科研院所和企业记录，论文按真实发布时间倒序。

纽约当前若没有直接归属论文，则显示“当前论文库暂无直接归属记录”，仍可作为地理观察入口，但不显示别处论文。

## 页面结构

地图舞台新增一个轻量的“科研城市”导航层：

- 桌面端位于左下方，避开右侧图例和详情抽屉。
- 移动端为横向可滚动的胶囊列表，保持地图可操作面积。
- 每个入口显示城市名、论文数和核心/活跃标记。
- 当前抵达城市具有明确选中态，并在地图上显示短暂的抵达标题。

现有图例、悬停卡片、详情抽屉和 2D/3D 切换继续保留。详情抽屉改为城市聚合内容，避免北京的高校和企业被拆成多个无法理解的重复城市。

## 三维渲染

继续使用 MapLibre GL JS 6.15 与 AWS Terrarium 全球高程，不引入 Cesium、Three.js 或新的运行时依赖。

### 样式层级

1. Esri `World_Physical_Map`：低缩放自然地貌底色。
2. Esri `World_Topo_Map`：超过 Physical 原生层级后接替，避免放大模糊。
3. 独立 `raster-dem` 地形源：生成三维网格。
4. 独立 `raster-dem` hillshade 源：增强山脊与谷地，不与地形网格共用 source。
5. Esri 边界与地名参考层。
6. 城市与论文 HTML marker。

Physical raster 使用小幅饱和度、对比度和亮度调整，恢复鲜明蓝海、绿地与棕色山脉；hillshade 使用偏暖阴影和浅色高光。MapLibre `sky` 提供克制的天际雾化，但不加入天气、波浪、昼夜循环等高成本效果。

### 镜头行为

- 首次进入 3D：沿用当前二维中心，`pitch` 约 36°，地形夸张 `1.0`。
- 点击城市：第一段飞至区域切入点，第二段飞至城市中心，最终 `pitch` 约 58–65°。
- 北京、杭州、新加坡和纽约使用人工调校的 bearing/zoom；自动补充城市使用经纬度方向生成的稳定默认镜头。
- 用户拖拽、缩放或旋转会自然打断动画，不启动自动循环旋转。
- `prefers-reduced-motion: reduce` 时取消两段动画，直接跳到最终镜头。

## 性能与容错

- Leaflet、`map_data.json` 和现有 marker 仍构成首屏；不预载 MapLibre、DEM 或额外城市图片。
- 城市导航只使用已加载的 `map_data.json`，不产生新请求。
- 进入 3D 后才加载 MapLibre 和可视区域 DEM。
- DEM 连续三次错误、WebGL 不支持或 MapLibre 初始化失败时，回到同一中心和缩放级别的 Leaflet 地图。
- 天空、样式增强或动画失败不得触发整图失败；只有地形主链路失败才回退。
- 城市图片沿用现有 WebP 和按需轮播，不新增自动一秒预加载整组图片的行为。

## 可访问性

- 城市导航使用真实 `button`，包含城市名、论文数和操作说明。
- 当前城市用 `aria-pressed` 表达。
- 抵达状态通过现有 `role=status` 区域播报。
- 键盘可完成 2D/3D 切换、城市选择、marker 详情和关闭。
- 减弱动态偏好下禁用飞行动画和脉冲装饰。

## 测试与证据

### 自动化测试

- 城市聚合：同城 school/company 合并，论文和机构正确去重。
- 核心城市：北京、杭州、新加坡、纽约始终存在；纽约无论文时保持零。
- 动态排名：最近论文和机构数量可改变非核心城市顺序。
- 页面契约：存在城市导航、抵达状态、3D 按需入口。
- 三维样式：独立 terrain/hillshade source、raster 色彩参数、sky、动态 exaggeration、两段式 flyTo 和 reduced-motion 分支。
- 回退：保留三次 DEM 错误恢复 Leaflet 的行为。

### 浏览器证据

- 二维初始视图截图：核心城市入口可见，地图仍可操作。
- 三维全球截图：海陆颜色、山脊和天空层次清楚。
- 北京、杭州、新加坡、纽约各一张抵达截图。
- 城市聚合详情截图：同城高校和企业同时出现，论文数与 JSON 一致。
- 网络记录：未点击 3D 前没有 MapLibre/DEM 请求。
- 故障注入：阻断 DEM 后自动回到二维。
- reduced-motion：无连续飞行动画且功能完整。

## 不在本次范围

- 真实海浪、云层、天气和昼夜系统。
- 全球 3D 建筑或倾斜摄影模型。
- 新增城市论文归属推断或修复历史错误坐标。
- 为没有现有数据的城市生成虚构论文、机构或城市照片。
